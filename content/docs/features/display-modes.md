# Display Modes

The View menu decides how many pages Galley shows at once, and how they are
arranged. Your choice is remembered across launches.

| Mode | Shortcut | Shows |
|------|----------|-------|
| Single Page | `Cmd + 1` | One page, no scrolling past its edges |
| Single Page Continuous | `Shift + Cmd + 1` | One page wide, scrolling through the document |
| Two Pages | `Cmd + 2` | A two-page spread |
| Two Pages Continuous | `Shift + Cmd + 2` | Two pages wide, scrolling through the document |

## Book Mode

View ▸ Book Mode changes where the spread starts. Off, pages pair up as
1–2, 3–4, and so on. On, page 1 sits alone as the cover and the spreads become
2–3, 4–5 — which is how the sheets actually fall in a bound book.

Turn it on whenever you are proofing something that will be printed and bound;
it puts the same pages side by side that the reader will see.

## Right-To-Left

View ▸ Right-To-Left reverses the reading order of a spread, so page 2 sits to
the left of page 3 rather than to its right.

This is what you want for Japanese 縦書き documents and anything else bound on
the right edge. Combined with Book Mode it gives the correct spread for a
right-opening book: the cover alone, then each spread reading right to left.

Both settings apply to the two-page modes. They have no visible effect while a
single-page mode is active, but they are remembered, so switching to a
two-page mode later picks them up.
